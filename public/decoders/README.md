Decoders for compressed glTF assets, copied from `three/examples/jsm/libs`
(three 0.180.0) so nothing is fetched from a third-party CDN:

- `basis/` — KTX2 / Basis Universal texture transcoder
- `draco/` — Draco mesh decoder

Meshopt decoding is built into three's GLTFLoader and needs no files.
Update these when upgrading three.
